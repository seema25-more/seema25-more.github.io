Built a Flask-based web application to deploy an analytical prediction model, allowing users to interact with the model through a simple web interface.

### Key Contributions

- Integrated trained models into a Flask backend.
- Demonstrated end-to-end analytics flow from data to user-facing output.
- Focused on usability and clarity for non-technical users.
